# Privacy policy

**Last updated: October 7, 2026**

YouTube Ad & Shorts Controls is an unofficial, community-built Chrome extension. It does not collect analytics, browsing history, account identifiers, video content, or personal information for the developer. It does not contain advertising, trackers, or a developer-operated backend.

## Data stored by the extension

The extension stores two settings, `enabled` and `hideShorts`, using Chrome's `storage.sync` API so the user's preferences can persist and may synchronize through Chrome when Chrome Sync is enabled. The extension does not send these settings to the developer or another third party. Chrome's handling of synchronized settings is governed by Google's privacy terms and the user's Chrome account settings.

## Website access and processing

The extension runs on `https://www.youtube.com/*`. It locally inspects YouTube page elements and, while enabled, applies its declared request filters and removes selected ad-related fields from YouTube player responses. This processing is performed in the browser to provide the extension's disclosed features; the extension does not log or export the page data.

## Changes and contact

This policy will be updated if the extension's data practices change. For privacy questions, contact the project maintainer through the repository's issue tracker after the public repository URL has been selected. Do not post private account information in public issues.
