# Privacy policy

**Last updated: October 7, 2026**

YouTube Ad & Shorts Controls is an unofficial, community-built Chrome extension. To provide its ad and Shorts controls, it locally processes selected YouTube page elements, YouTube request URLs, and selected fields in YouTube player responses. This is user browsing activity and website content. Processing happens in the browser and is limited to the extension's stated purpose; this page data is not sent to or collected by the developer. The extension does not contain analytics, advertising, trackers, or a developer-operated backend.

## Data stored by the extension

The extension stores two Boolean settings, `enabled` and `hideShorts`, using Chrome's `storage.sync` API. When Chrome Sync is enabled, Chrome may synchronize these preferences through the user's Google account so they persist across signed-in Chrome instances. The extension developer does not receive the settings. Google's handling of synchronized settings is governed by Google's privacy terms and the user's Chrome account settings.

## Website access and processing

The extension runs on `https://www.youtube.com/*`. It locally inspects YouTube page elements to apply the user's ad and Shorts settings and, while ad handling is enabled, applies its declared request filters and removes selected ad-related fields from YouTube player responses. This processing is necessary for the extension's disclosed user-facing features. The extension does not log, retain, or transmit this page data to the developer or another party. It does not use page data for advertising, profiling, or unrelated purposes, and the developer does not access it.

The extension follows the Chrome Web Store User Data Policy's Limited Use requirements: YouTube page data is used only to provide the extension's disclosed features, is not sold or transferred for unrelated purposes, is not used for personalized advertising, and is not made available for human review. Optional feedback is a separate user-initiated submission to GitHub as described below.

## Optional feedback

The popup contains a link to GitHub issue forms. Nothing is sent automatically. If the user chooses to open and submit a report, the information they enter is sent to GitHub and may be publicly visible under GitHub's terms and privacy policy. The developer can read reports submitted to the public issue tracker to respond to the user's request. Reports should not contain passwords, cookies, account details, or private video links.

## Changes and contact

This policy will be updated if the extension's data practices change. For privacy questions, contact the project maintainer through the public repository's issue tracker: https://github.com/harish-kunta/YoutubeAdBlock/issues. Do not post private account information in public issues.
