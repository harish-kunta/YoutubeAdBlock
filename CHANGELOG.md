# Changelog

## 1.0.3 — release candidate

- Serialize network-rule updates to prevent stale rules after rapid setting changes.
- Log rule installation failures and clean up the retired rule ID on upgrade.
- Add automated service-worker behavior checks and a GitHub Actions package validation workflow.
- Keep known free-with-ads movie rendering failures documented as an unresolved release blocker.

## 1.0.2

- Added popup link to guided playback/ad reports and general feedback.
- Added GitHub issue forms that collect browser, extension, YouTube surface, and reproduction details only when a user submits a report.
- Disclosed that submitted feedback goes to GitHub and may be public; no automatic usage reports are sent.

## 1.0.1

- Prepared Chrome Web Store metadata, icons, privacy and listing drafts, package script, and publishing checklist.
- Reduced repeated Shorts-page scans and made player filtering wait for the saved user setting.
